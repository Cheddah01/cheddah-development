# Cheddah Development

The public hub and portfolio for Cheddah Development Minecraft plugins.

## Local development

```bash
npm install
npm run dev
```

## Deployment

Pushing `main` deploys the static site to GitHub Pages through the included workflow.

The production site is published at `https://cheddah-development.net`. GitHub Pages handles the custom-domain mapping while the workflow builds the site for the domain root.
